# basic-bigram-model
a simple bigram language model to generate names keeping 1 character as a context generate the next character, we see that at first the names generated are nonsensical but as we optimize further we get more better name like words generated and reduced training losses

The figure below shows vertically the current character that we have at hand and the horizontal rows represent the character that comes next and the numnbers indicate the total no of such pairs in the inputted names.txt file
